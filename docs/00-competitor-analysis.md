## Top 4 Design Inspiration Sources

### → INSPIRATION 1: DesignCafe
**Use for:** Lead generation layout, CTA strategy, sticky header

| Element to Copy | How to Implement |
|---|---|
| Permanent "Get Free Estimate" sticky button in header | Gold button (Timber Gold #C49A3C), persists on every scroll |
| Multi-channel top bar | WhatsApp number + CTA button + phone in same header row |
| Cost Calculator widget | Multi-trade dropdown: Carpentry / Electrical / Painting / Tiles / Plumbing + area input → range output |
| Abandoned booking recovery | Pill notification: "You have 2 steps left — continue your estimate" |
| Differentiator ticker bar | Horizontal scroll: "ISO Certified · 500+ Projects · 45-Day Delivery · No Hidden Costs · Free 3D Design" |

---

### → INSPIRATION 2: Vinra Interiors
**Use for:** SEO content architecture, before/after slider, font pairing

| Element to Copy | How to Implement |
|---|---|
| Design Encyclopedia / Resource Hub | "Complete Home Owner's Guide" — 10 articles on plywood, electrical standards, paint finishes, tile types |
| Neighbourhood SEO landing pages | `/services/koramangala` `/services/hsr-layout` `/services/whitefield` etc. |
| Before/after drag-reveal slider | 3-4 transformation showcases on homepage + every project page |
| Anchor-linked service sections | One `/services` page with #carpentry, #electrical, #painting, #tiles, #plumbing anchors |
| Font pairing | Cormorant Garamond (headings) + Plus Jakarta Sans (body) |

---

### → INSPIRATION 3: The KariGhars
**Use for:** Trust building, emotional headlines, lead qualification

| Element to Copy | How to Implement |
|---|---|
| Budget-qualifying lead form | Options: Under ₹5L / ₹5-15L / ₹15-30L / ₹30L+ |
| Developer property credentials | "We've worked inside Prestige / Brigade / Sobha / Embassy developments in Bangalore" |
| Award & media citation strip | Logo marquee: Google Verified / any local press coverage / association logos |
| Emotional headline formula | "One Team. Every Trade. Your Complete Home." (not generic "Best Interior in Bangalore") |
| Dark portfolio card components | Dark (#272727) card backgrounds, gold overlay text on portfolio hover |

---

### → INSPIRATION 4: ADDON Interiors
**Use for:** Multi-trade service architecture, trust badges, partner logos

| Element to Copy | How to Implement |
|---|---|
| Multi-trade service category model | Top level: Residential / Commercial. Sub-level: Carpentry / Electrical / Painting / Tiles / Plumbing |
| "100% In-House, Zero Subcontracting" | Hero section + ticker + About page — biggest differentiator for multi-trade |
| Video hero with "Watch Video" CTA | 90-sec video: site walk → craftsmen → happy client handover |
| Partner/material brand logo wall | Group by trade: Tiles (Kajaria/RAK) · Paint (Asian Paints/Dulux) · Electrical (Legrand/Havells) · Hardware (Hettich/Blum) |
| Glassmorphism trust badges | 5 frosted-glass badges below hero: ISO Certified · 500+ Projects · Bangalore-Based · In-House Team · 5-Year Warranty |

## Gaps No Competitor Has — Build These First

| Gap | Your Opportunity |
|---|---|
| No unified multi-trade cost calculator | One calculator: all 6 trades in one tool — **first in Bangalore** |
| No trade-specific portfolio filter | Filter gallery by: Carpentry / Electrical / Painting / Tiles / Plumbing |
| No transparent milestone payment display | Show: 10% booking → 40% materials → 40% execution → 10% handover |
| No thumb-friendly "Call Now" in mobile hero | Large 56px+ call button directly in hero on mobile |
| No pre-filled WhatsApp with trade selection | "Hi, I need a quote for [trade] for my [flat type] in [area]..." |
